## 1.6 Android Audio版本演进

> 主线为 **Android 12L/API 32**（本库基准）；13/14 行所述机制不在本树，仅作演进背景（详见 [1.7](01_1.7_AOSP14_Audio新特性架构演进.md)）。

| 版本 | 年份 | 关键变更 |
|------|------|----------|
| 1.5 | 2009 | AudioTrack/AudioRecord基础API |
| 2.3 | 2010 | AudioEffect框架（API 9） |
| 4.1 | 2012 | FastMixer低延迟路径 |
| 4.4 | 2013 | 重新设计AudioPolicyManager |
| 5.0 | 2014 | AudioAttributes替代stream type；Project Volta音频优化 |
| 6.0 | 2015 | MMAP低延迟模式 |
| 7.0 | 2016 | 多声道PCM直通 |
| 8.0 | 2017 | AAudio API；AudioFocusRequest；Treble HAL(HIDL) |
| 9.0 | 2018 | AudioPlaybackConfiguration；VolumeGroup |
| 10 | 2019 | CapturePreset合规；Audio HAL 5.0 |
| 11 | 2020 | AudioProductStrategy API；麦克风隐私指示；Audio HAL 6.0 |
| 12 | 2021 | Spatializer API；LE Audio预备；Audio HAL 7.0（本树为 12L，含 HIDL 7.0） |
| 13 | 2022 | VolumeInfo API；LE Audio正式支持；Audio HAL AIDL（IModule） |
| 14 | 2023 | SoundDose听力保护；AudioControl HAL AIDL v3；BitPerfectThread(AAOS) |
