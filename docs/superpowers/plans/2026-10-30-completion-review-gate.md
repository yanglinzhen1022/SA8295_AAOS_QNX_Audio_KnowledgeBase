# 整体完成与独立 Review 验收约束

用户于本轮补充：目标完成后，新起一个 agent review；发现问题则修改并复审，直到没有待解决问题并达到目标。若一天后的同一时间尚未完成，可以停止。

## 时间与范围

- 本次读取环境时钟：2026-10-30T19:00:34+08:00。
- 可停止的时间界限：2026-10-31T19:00:34+08:00。
- 这是允许未完成时停止的界限，不是整体完成承诺，也不是后台调度器已启动的声明。
- 整体目标沿用 `docs/superpowers/specs/2026-10-30-audioreach-knowledge-base-design.md`；单批正文或静态检查通过不等于整体完成。

## 执行清单

- [ ] 继续源码驱动改造，保留原分支与文档修改边界；每批做静态校验和作者自审。
- [ ] 整体达到设计目标后，新起独立上下文 reviewer agent，提供原始要求、设计、完整改造范围与可见源码，不让作者自审冒充独立 review。
- [ ] Reviewer 检查整体知识库的解释、链路、图、片段、版本/执行域边界、导航与遗留矛盾，不限于最新提交。
- [ ] 对每项发现核对源码，修复有效问题；有异议时给出证据并请 reviewer 再判断，不静默忽略。
- [ ] 修改后重新静态校验并复审，直至没有待解决问题。保留实际 reviewer 结果、范围和未验证事项，不能将静态 review 说成实机正确性证明。
- [ ] 最终报告实际提交、验证和独立 review 状态；若到期仍未完成，记录剩余任务、风险及停止时工作区状态。

## 子代理执行边界

用户授权的是整体完成后的独立 review，不自动扩展为并行改写全部章节。正式派发前检查可执行 agent 能力并读取 pi-subagents 协议；多步委派使用一个顶层异步 workflow，reviewer 只读，由父会话修改，保持单一 writer。若子代理基础设施失败，记录准确错误和仓库状态并报告，不静默改用外部 CLI。
