### 14.4.1 SCO音频架构

SCO(Synchronous Connection-Oriented)是蓝牙通话语音的传输通道，HFP(Hands-Free Profile)建立在SCO之上管理通话状态。在AOSP14中，SCO音频由[`BtHelper`](frameworks/base/services/core/java/com/android/server/audio/BtHelper.java:54)和[`AudioDeviceBroker`](frameworks/base/services/core/java/com/android/server/audio/AudioDeviceBroker.java)协同管理。

```mermaid
graph TB
    subgraph Application层
        AM_API[AudioManager<br>startBluetoothSco<br>stopBluetoothSco]
        BT_HFP_API[BluetoothHeadset<br>HFP公共API]
    end

    subgraph Framework层
        BTH[BtHelper<br>SCO状态管理+HFP代理]
        ADB[AudioDeviceBroker<br>SCO设备路由+Suspend控制]
    end

    subgraph 蓝牙服务层
        HFP_SVC[HeadsetService<br>HFP协议服务]
        HFP_SM[HeadsetStateMachine<br>HFP状态机]
    end

    subgraph Audio HAL层
        IBT_SCO[IBluetooth<br>AIDL SCO/HFP配置]
        SCO_HAL[SCO音频数据通道]
    end

    AM_API --> BTH
    BT_HFP_API --> HFP_SVC
    BTH --> ADB
    HFP_SVC --> HFP_SM
    BTH --> HFP_SVC
    IBT_SCO --> SCO_HAL
```

**BtHelper SCO核心字段**（源码[`BtHelper.java:80-116`](frameworks/base/services/core/java/com/android/server/audio/BtHelper.java:48)）：

| 字段 | 类型 | 说明 |
|------|------|------|
| `mScoConnectionState` | int | SCO连接状态(由蓝牙Headset报告) |
| `mScoAudioState` | int | SCO音频状态机当前状态 |
| `mScoAudioMode` | int | SCO音频模式(VIRTUAL_CALL/VR) |
| `mBluetoothHeadset` | BluetoothHeadset | HFP Profile代理 |
| `mBluetoothHeadsetDevice` | BluetoothDevice | 当前HFP活动设备 |

### 14.4.2 SCO音频状态机

SCO音频有6个状态，由[`BtHelper.mScoAudioState`](frameworks/base/services/core/java/com/android/server/audio/BtHelper.java:48)管理：

```mermaid
stateDiagram-v2
    [*] --> INACTIVE
    INACTIVE --> ACTIVATE_REQ: startScoAudio<br>Headset未连接
    INACTIVE --> ACTIVE_EXTERNAL: BT端发起VR或通话<br>STATE_AUDIO_CONNECTING
    INACTIVE --> ACTIVE_INTERNAL: AudioManager.startBluetoothSco<br>Headset已连接
    ACTIVATE_REQ --> ACTIVE_INTERNAL: Headset连接完成<br>connectBluetoothScoAudioHelper
    ACTIVE_EXTERNAL --> DEACTIVATING: BT端停止SCO
    ACTIVE_INTERNAL --> DEACTIVATING: stopBluetoothSco<br>或stopScoAudio
    DEACTIVATING --> INACTIVE: STATE_AUDIO_DISCONNECTED
    DEACTIVATING --> ACTIVATE_REQ: 有新的SCO请求排队
    ACTIVE_INTERNAL --> DEACTIVATE_REQ: 停止请求中<br>Headset未连接
```

**SCO状态常量**（源码[`BtHelper.java:92-103`](frameworks/base/services/core/java/com/android/server/audio/BtHelper.java:48)）：

| 常量 | 值 | 说明 |
|------|------|------|
| `SCO_STATE_INACTIVE` | 0 | SCO未激活 |
| `SCO_STATE_ACTIVATE_REQ` | 1 | SCO激活请求等待Headset服务连接 |
| `SCO_STATE_ACTIVE_EXTERNAL` | 2 | SCO由BT端激活(语音识别或通话) |
| `SCO_STATE_ACTIVE_INTERNAL` | 3 | SCO由AudioManager API激活 |
| `SCO_STATE_DEACTIVATE_REQ` | 4 | SCO去激活请求等待Headset服务连接 |
| `SCO_STATE_DEACTIVATING` | 5 | SCO去激活进行中，等待BT意图 |

### 14.4.3 SCO激活流程详解

#### 内部激活(App发起)

当App调用`AudioManager.startBluetoothSco()`时：

```mermaid
sequenceDiagram
    participant APP as Application
    participant AM as AudioManager
    participant ADB as AudioDeviceBroker
    participant BTH as BtHelper
    participant HFP as BluetoothHeadset
    participant STACK as BT Stack

    APP->>AM: startBluetoothSco()
    AM->>ADB: startBluetoothScoForClient()
    ADB->>BTH: startBluetoothSco()
    BTH->>BTH: requestScoState(REQ_START, SCO_MODE_VIRTUAL_CALL)
    BTH->>BTH: 检查mBluetoothHeadset是否可用
    alt Headset已连接
        BTH->>HFP: connectBluetoothScoAudioHelper<br>startScoUsingVirtualVoiceCall
        HFP->>STACK: 建立SCO连接
        STACK-->>BTH: STATE_AUDIO_CONNECTED
        BTH->>BTH: mScoAudioState = SCO_STATE_ACTIVE_INTERNAL
        BTH->>ADB: setBluetoothScoOn(true)
    else Headset未连接
        BTH->>BTH: mScoAudioState = SCO_STATE_ACTIVATE_REQ
        BTH->>BTH: 等待Headset连接回调
    end
```

#### 外部激活(BT端发起)

当蓝牙耳机端发起语音识别或通话时：

```mermaid
sequenceDiagram
    participant EARPHONE as 蓝牙耳机
    participant STACK as BT Stack
    participant HFP as HeadsetService
    participant BTH as BtHelper
    participant ADB as AudioDeviceBroker

    EARPHONE->>STACK: 发起语音识别或通话
    STACK->>HFP: ACTION_AUDIO_STATE_CHANGED
    HFP->>BTH: receiveBtEvent(ACTION_AUDIO_STATE_CHANGED)
    BTH->>ADB: postScoAudioStateChanged(STATE_AUDIO_CONNECTING)
    ADB->>BTH: onScoAudioStateChanged(STATE_AUDIO_CONNECTING)
    BTH->>BTH: mScoAudioState = SCO_STATE_ACTIVE_EXTERNAL
    STACK->>HFP: STATE_AUDIO_CONNECTED
    HFP->>BTH: receiveBtEvent(ACTION_AUDIO_STATE_CHANGED)
    BTH->>ADB: postScoAudioStateChanged(STATE_AUDIO_CONNECTED)
    ADB->>BTH: onScoAudioStateChanged(STATE_AUDIO_CONNECTED)
    BTH->>ADB: setBluetoothScoOn(true)
```

### 14.4.4 onScoAudioStateChanged核心逻辑

[`onScoAudioStateChanged()`](frameworks/base/services/core/java/com/android/server/audio/BtHelper.java:315)是SCO状态变化的核心处理方法：

**STATE_AUDIO_CONNECTED处理**（源码[`BtHelper.java:288-298`](frameworks/base/services/core/java/com/android/server/audio/BtHelper.java:48)）：

```java
case BluetoothHeadset.STATE_AUDIO_CONNECTED:
    scoAudioState = AudioManager.SCO_AUDIO_STATE_CONNECTED;
    if (mScoAudioState != SCO_STATE_ACTIVE_INTERNAL
            && mScoAudioState != SCO_STATE_DEACTIVATE_REQ) {
        mScoAudioState = SCO_STATE_ACTIVE_EXTERNAL;  // 外部激活
    } else if (mDeviceBroker.isBluetoothScoRequested()) {
        broadcast = true;  // 内部请求已确认，广播状态
    }
    mDeviceBroker.setBluetoothScoOn(true, "BtHelper.receiveBtEvent");
    break;
```

**STATE_AUDIO_DISCONNECTED处理**（源码[`BtHelper.java:299-321`](frameworks/base/services/core/java/com/android/server/audio/BtHelper.java:48)）：

```java
case BluetoothHeadset.STATE_AUDIO_DISCONNECTED:
    mDeviceBroker.setBluetoothScoOn(false, "BtHelper.receiveBtEvent");
    // 检查是否有排队的新SCO请求
    if (mScoAudioState == SCO_STATE_ACTIVATE_REQ) {
        // 立即重新连接SCO
        if (connectBluetoothScoAudioHelper(...)) {
            mScoAudioState = SCO_STATE_ACTIVE_INTERNAL;
            broadcast = true;
            break;
        }
    }
    mScoAudioState = SCO_STATE_INACTIVE;
    break;
```

### 14.4.5 SCO音频模式

SCO支持三种音频模式（源码[`BtHelper.java:106-112`](frameworks/base/services/core/java/com/android/server/audio/BtHelper.java:48)）：

| 常量 | 值 | 说明 |
|------|------|------|
| `SCO_MODE_UNDEFINED` | -1 | 模式未定义 |
| `SCO_MODE_VIRTUAL_CALL` | 0 | 虚拟语音呼叫模式(BluetoothHeadset.startScoUsingVirtualVoiceCall) |
| `SCO_MODE_VR` | 2 | 语音识别模式(BluetoothHeadset.startVoiceRecognition) |

模式选择逻辑：
- App target API < JB MR2 → `SCO_MODE_VIRTUAL_CALL`
- App target API >= JB MR2 → `SCO_MODE_VIRTUAL_CALL`(AudioManager.startBluetoothSco)
- 语音识别场景 → `SCO_MODE_VR`

### 14.4.6 SCO与A2DP/LE Audio互斥机制

> **版本边界（负结论）**：`updateAudioHalBluetoothState()`/`mBluetoothAudioStateLock`/`mBluetoothA2dpSuspendedInt`/`LeAudioSuspended` 状态组（AudioDeviceBroker.java:893-1019，Android 13）**不在本树**。12L 的 SCO/A2DP 互斥：SCO 状态机在 `BtHelper`（mScoAudioState），SCO 复位时由 [`resetBluetoothSco()`](frameworks/base/services/core/java/com/android/server/audio/BtHelper.java:443) 写 `AudioSystem.setParameters("A2dpSuspended=false")`（:446）恢复 A2DP；挂起期间 A2DP 数据路径由 audio HAL/栈侧依据 SCO 占用处理（`audio_a2dp_hw` 检查 SCO 状态过滤）。概念性互斥关系（下表）在 12L 仍成立，但实现不是 13 的统一状态机：

```mermaid
flowchart TB
    SCO_START[SCO激活 setBluetoothScoOn true] --> BTH[BtHelper SCO状态机<br>mScoAudioState]
    BTH --> HAL[Sco opened / closed<br>经栈与HAL协同]
    SCO_STOP[SCO断开] --> RESET[BtHelper.resetBluetoothSco<br>:443]
    RESET --> A2DP_RES[AudioSystem.setParameters<br>A2dpSuspended=false :446]
    RESET --> SCO_OFF[mDeviceBroker.setBluetoothScoOn false]
```

**互斥关系总结**：

| 事件 | A2DP状态 | LE Audio状态 | SCO状态 |
|------|----------|-------------|---------|
| SCO激活 | Suspended | Suspended | Active |
| SCO断开 | Resumed | Resumed | Inactive |
| A2DP活跃 | Active | 可并行或Suspended | 非活跃 |
| LE Audio活跃 | 可并行或Suspended | Active | 非活跃 |

### 14.4.7 SCO/HFP运行时配置（12L：无AIDL IBluetooth，ScoConfig/HfpConfig为Android 14）

> **版本边界（负结论）**：AIDL `IBluetooth`（audio AIDL core，`setScoConfig(ScoConfig)`/`setHfpConfig(HfpConfig)`）是 **Android 14** 接口，本树不存在。12L 的 SCO 配置通道：
> - Java→Native：`AudioManager.startBluetoothSco()`/`setBluetoothScoOn()` → `AudioDeviceBroker.setBluetoothScoOn()`（:650）→ BtHelper SCO 状态机（`mScoAudioMode` VR/VIRTUAL_CALL）。
> - HFP 协议侧：`system/bt` 的 `bta_ag_*`（AG 角色动作/AT 命令解析）；NREC/带宽等 AT 参数经 HSP/HFP 协议下发，不经 audio HAL。
> - audio HAL 侧无 SCO 专设配置接口（12L HIDL `IDevice` 无 setScoConfig 对应物）。

### 14.4.8 SCO音频设备类型

SCO在Audio系统中映射为多种设备类型：

| 设备类型 | 说明 | 使用场景 |
|----------|------|----------|
| DEVICE_OUT_BLUETOOTH_SCO | SCO输出 | 通话语音输出到蓝牙耳机 |
| DEVICE_OUT_BLUETOOTH_SCO_HEADSET | SCO耳机输出 | 蓝牙耳机通话 |
| DEVICE_OUT_BLUETOOTH_SCO_CARKIT | SCO车载输出 | 车载免提通话 |
| DEVICE_IN_BLUETOOTH_SCO_HEADSET | SCO麦克风输入 | 蓝牙耳机麦克风录音 |

### 14.4.10 AAOS车载SCO场景

| 场景 | 实现方式 | 关键点 |
|------|----------|--------|
| 车载免提通话 | SCO_WB/SCO_SWB模式 | DEVICE_OUT_BLUETOOTH_SCO_CARKIT |
| 语音识别 | SCO_MODE_VR模式 | startVoiceRecognition() |
| 通话时自动暂停媒体 | SCO激活→Suspend A2DP/LE Audio | updateAudioHalBluetoothState互斥 |
| 多麦克风阵列降噪 | HFP NREC配置 | ScoConfig.isNrecEnabled=true |
| 紧急通话优先 | SCO最高音频优先级 | AudioMode.IN_CALL强制SCO路由 |
