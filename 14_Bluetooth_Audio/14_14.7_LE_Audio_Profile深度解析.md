## 14.7 LE Audio Profile 深度解析 — 兼容入口（Android 13+，不在本树）

> **版本边界（更正）**：本树 12L 已有早期 LE Audio Java 实现（`packages/apps/Bluetooth/.../le_audio/`：LeAudioService 844 行/LeAudioStateMachine/LeAudioNativeInterface，见 [14.3](14_14.3_LE_Audio-低功耗蓝牙音频.md)）；**不在本树**的是 13+ 的 mainline 完整栈——`LeAudioCodecConfig`（LC3 协商）、`bta/le_audio/` native 状态机组（UnicastStateMachine/GroupStreamManager/AudioStreamConfiguration）、TMAP 角色协商、UCS/ACD 场景配置。本树 native 侧仅有 HAL 接口雏形（`le_audio_software.cc` + 102 行 btif 桩）。原稿的组流管理、设备成员管理等深度细节无本树源码支撑，按版本边界移除。

### 概念速览（版本限定）

- **CIS/ASE 流**：每个 LE Audio 设备的每个方向有 ASE（Audio Stream Endpoint）,经 ASMA/P 建立同步流。
- **组（CIG/CIS Group）**：`GroupId` 维度管理多设备同步（12L `btif_le_audio.cc` 的 `GroupStatus` 回调仅为组状态的占位枚举）。
- **TMAP/UMR**：终端能力与多角色声明（Android 14 完善）。
- **Android 13+ 才有**：`mIsLeOutput` 路由区分、`postSetLeAudioVolumeIndex` 绝对音量。（**勘误**：`BluetoothLeAudio` framework API 与 `DEVICE_OUT_BLE_HEADSET` 在本树**已存在**——frameworks/base/core/java/android/bluetooth/BluetoothLeAudio.java 为 12L 早期公共 API；AudioSystem.java:943 已有该常量，只是 BtHelper/路由侧无集成。）

### 本树可验证的相邻主题

- 蓝牙音频 HAL 会话底座：`system/bt/audio_hal_interface/client_interface.*`（A2DP 与 LE 共用）。
- 音频侧设备接入框架（A2DP/HearingAid/SCO 为主）：[14.6](14_14.6_蓝牙音频设备与AudioDeviceBroker交互.md)。
- 产品音频策略不含 BLE 设备：[11.5](../11_Vendor_Layer/11_11.5_car_audio_configuration.xml-AAOS车载配置.md)。
